# 元データ取得方針

## 1. 法的根拠

財務省「公共調達の適正化について」（財計第2017号、2006年制定・随時改正）に基づき、各省庁は一定金額以上の契約情報を公表する義務を負う。防衛省はその第3項（情報の公表）に基づき、省内各機関の契約情報を公表している。

- 財務省通知: https://www.mof.go.jp/policy/budget/topics/public_purchase/koukyou/koukyou_02.htm
- 防衛省公共調達の適正化について: https://www.mod.go.jp/j/budget/release/jouhou.html
- 防衛省調達機関リンク集: https://www.mod.go.jp/j/budget/chotatsu/ichiran.html

## 2. 公表対象4分類

財務省通知では、以下の4分類ごとに別表で契約情報を公表することが求められている。

| 分類 | 内容 | 対象例 |
|------|------|--------|
| **公共工事（競争契約）** | 工事・建設に係る一般競争・指名競争入札 | 庁舎改修、護岸工事、滑走路整備 |
| **公共工事（随意契約）** | 工事・建設に係る随意契約 | 特定技術者しか施工できない特殊工事 |
| **物品役務（競争契約）** | 物品購入・業務委託に係る一般競争・指名競争入札 | 装備品購入、整備委託、情報システム |
| **物品役務（随意契約）** | 物品購入・業務委託に係る随意契約 | 特定メーカー限定の装備品、FMS調達 |

公表の閾値（財計第2017号基準）:
- 工事: 250万円超
- 物品役務: 160万円超（競争）、80万円超（随意）

## 3. 収集フロー

### Step 1: 防衛省「公共調達の適正化について」ページ

```
https://www.mod.go.jp/j/budget/release/jouhou.html
```

省内各機関へのリンクが掲載されているが、すべての調達機関をカバーしているわけではない。

### Step 2: 調達機関リンク集の活用

```
https://www.mod.go.jp/j/budget/chotatsu/ichiran.html
```

防衛省・自衛隊の全調達機関（20機関カテゴリ）へのリンク集。  
リンク先は各組織のトップページであり、そこからさらに各基地・部隊・補給処のページへ深掘りが必要。

### Step 3: 各機関ページでのファイル収集

各機関ページに掲載されているExcel / PDF / HTMLテーブル形式の契約実績ファイルを収集する。

**ファイル命名パターン例:**
```
rakusatsu{RYMM}.xlsx     # 落札結果（和暦年月）
zuikei{RYMM}.xlsx        # 随意契約結果
kouhyou-n-{RYMM}.xlsx   # 入札結果（n=入札）
kouhyou-z-{RYMM}.xlsx   # 随契結果（z=随意）
kekka_{YY}.pdf           # 契約結果PDF
{YYMM}_k.xlsx            # 工事（_k suffix）
{YYMM}_b.xlsx            # 物品役務（_b suffix）
```

**収集対象キーワード:**
- ページ内リンク: 契約に係る情報の公表 / 契約結果 / 公共調達 / 随意契約 / 競争契約
- URLパターン: rakusatsu / zuikei / kekka / kouhyou / kouji / bukka / yakumu
- ファイル形式: .xlsx / .xls / .pdf（HTMLテーブル形式のものも存在）

### Step 4: WARPによる過去データ補完

国立国会図書館のWebアーカイブ（WARP）を使い、現在は公表期間を過ぎてライブサイトから削除されたFY2022〜2023分の契約情報を取得する。

```
https://warp.ndl.go.jp/{coll}/{ts}/{original_url}
```

WARPが必要な主な理由:
- 各機関は通常「直近2〜3年分」のみライブ掲載し、古いデータは削除する
- 画像スキャンPDFしかないケースでは、テキストPDFが残っているWARPスナップショットを活用

## 4. 収集の技術的制約

| 制約 | 内容 |
|------|------|
| Cookie認証 | WARP経由アクセスに必要（http_client.py で対応） |
| 画像PDF | OCRが必要（easyocr を使用） |
| HTMLテーブル | Excelとは別に `scrape_html_tables()` が必要 |
| ファイルなしページ | HTML直接掲載の機関がある（工期始を契約日代用） |
| 403/404 | 一部機関はWARPでも取得不可（asdf_kasuga等） |
