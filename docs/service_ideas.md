# 防衛調達DB・ダッシュボード活用サービス案 10選（2026-06-13）

前提となるDBの強み:
- **個別契約 15.5万件**（FY2022–2025、約26.7兆円）— 官報や予算書には無い粒度
- **7本柱（防衛力整備計画）分類** — 契約を政策目標に紐付けた独自データ（他に存在しない）
- **要求元判定** — ATLA中央調達3万件を陸海空・統幕等に割り戻した独自推定
- **ベンダー・金額・落札率・随契理由・装備品紐付** の横断検索
- カバレッジ約97%（FY2024）を検証済み — 「ほぼ全量」を主張できる希少なデータセット

## 1. 防衛調達インテリジェンス・サブスク
- **概要**: 月次レポート＋ダッシュボードアクセス。競合他社の落札動向、新規案件の傾向、
  7本柱別の予算執行ペース（予算概要との対比はDBが契約ベースで揃っているため直接比較可能）。
- **使うDB資産**: contracts全量、contract_pillar、fy_budget、ベンダー別集計。
- **マネタイズ**: 法人サブスク。三菱重工・川重クラスより、中堅機器メーカー
  （年間受注数十億円規模）が「自社の立ち位置を知る」用途で刺さりやすい。
- **実現難度**: 低（既存ダッシュボードの法人向け整形＋月次PDF自動生成）。

## 2. 入札機会アラート＆過去価格レンジ
- **概要**: 「自社が納められる品目」のキーワードを登録すると、類似の過去契約
  （落札者・金額・落札率・発注機関）が出てきて、新規公表時に通知が届く。
- **使うDB資産**: contract_name 全文検索、award_rate、bid_method、月次の増分収集パイプライン。
- **マネタイズ**: セルフサーブの低額サブスク。防衛調達は新規参入障壁が情報面にある
  （どの機関が何をいくらで買うか分からない）ので、その情報格差を埋める。
- **実現難度**: 中（検索UI＋通知基盤。増分収集の定期運用が前提）。

## 3. データセット / API 販売
- **概要**: クリーニング済みCSV/SQLiteの年間ライセンス、またはREST API。
  7本柱分類・要求元判定済みである点が官公庁オープンデータとの決定的な差。
- **使うDB資産**: DB一式（再配布用にスキーマ文書とコードブック=docs/を整備済み）。
- **マネタイズ**: 報道機関（防衛特集の都度）・シンクタンク（NIDS/民間研究所）・
  海外のディフェンス系リサーチ会社（Janes等の日本カバレッジは薄い）。
- **実現難度**: 低（既にエクスポート機構あり）。注意: 出典明記・公表データ由来である旨の
  利用規約整備。

## 4. 防衛予算ウォッチ（メディア/ニュースレター）
- **概要**: 「43兆円の整備計画は実際どう使われているか」を契約ベースで定点観測する
  ニュースレター/サイト。四半期ごとに7本柱別の執行率・大型契約トップ10・随契比率を発信。
- **使うDB資産**: pillar×FY集計、予算（契約ベース）との対比 — 本DBの最も独自性が高い使い方。
- **マネタイズ**: 有料ニュースレター＋広告。メディア協業（共同調査報道）で認知獲得。
- **実現難度**: 低〜中（コンテンツ制作の継続力が本体）。

## 5. 随意契約・落札率 監査レポート
- **概要**: 随契80.7%（金額ベース）の構造、1社応札の常連、落札率99%超の契約一覧など、
  ガバナンス観点の定型レポート。議員質問・決算審査・報道の素材になる。
- **使うDB資産**: bid_method、award_rate、zuii_reason、vendor集計。
  ※監査レポートの品質は bid_method 正規化（監査A-3）完了が前提。
- **マネタイズ**: 案件ベース（政党・議員事務所・NPO・報道）。中立性の担保が商品価値。
- **実現難度**: 低（集計は容易）。レピュテーションリスク管理が肝。

## 6. サプライチェーン依存度分析
- **概要**: 特定装備カテゴリの供給者集中度（HHI）、単一供給源の特定、FMS依存の推移など。
  経済安保推進法対応のコンサル素材。
- **使うDB資産**: contract_equipment＋equipment_master、vendor_name_norm、FMS判定。
- **マネタイズ**: コンサルファーム・商社・損保への分析受託。
- **実現難度**: 中（装備品紐付12,743件をさらに拡充すると価値が上がる）。

## 7. 投資・M&A デューデリ支援
- **概要**: 防衛関連銘柄の「実際の受注額」を契約データで裏取りするレポート。
  IR資料の「防衛事業拡大」を定量検証できる。中堅上場企業（重工系部品・電子機器）の
  防衛売上推定は証券会社でも持っていない。
- **使うDB資産**: vendor別×FY別契約額の時系列、corporate_number（EDINET突合の鍵）。
- **マネタイズ**: 証券リサーチ・PEファンドへのスポット販売。
- **実現難度**: 中（corporate_number補完=監査B-1が精度を左右）。

## 8. 基地経済・地域分析レポート
- **概要**: 基地別（asdf_*/gsdf_*/msdf_*の機関粒度）・地方防衛局別の発注額と地元企業
  受注率。基地所在自治体の経済効果測定、地方紙の連載企画、地銀の法人営業資料。
- **使うDB資産**: agency_id（基地粒度で29+25+機関）、vendor_address。
- **マネタイズ**: 自治体・地方紙・地銀への受託レポート。
- **実現難度**: 低〜中（vendor_addressの地理コーディングを足すと価値倍増）。

## 9. 入札戦略支援SaaS
- **概要**: 入札参加前に「この機関のこの品目の過去落札価格レンジ・応札社数・
  リピート落札者」を提示し、応札価格の意思決定を支援。#2の上位版。
- **使うDB資産**: 同上＋estimated_price/award_rateの分布。
- **マネタイズ**: 月額SaaS。建設業界の入札支援SaaS（数千社規模の市場）の防衛版。
- **実現難度**: 高（UI/UX・継続データ更新・営業が必要）。#2で検証してから。

## 10. 学術パネルデータ提供
- **概要**: 防衛経済学・公共調達研究向けのクリーンなパネルデータ（匿名化不要・全て公表情報）。
  論文での引用・共同研究が信用資産になり、#3〜#7の営業材料に転化する。
- **使うDB資産**: DB一式＋方法論ドキュメント（docs/requester_logic.md 等が既にある）。
- **マネタイズ**: 直接収益は薄い。引用実績→「このDBは学術利用に耐える」という証明が本体。
- **実現難度**: 低（kit/のエクスポート機構をそのまま転用可能）。

# ポップ路線（ショート動画・SNS）追加6案（2026-06-13追記）

データの硬さを「テンポと意外性」に変換する路線。共通の武器は
**DBからスクリプト1本で動画素材（数字・ランキング・シェア%）を量産できる**こと。
1本あたりの制作コストを限界までゼロに近づけ、本数で勝負する。

## 11. 「この企業、実は国防支えてる？」1社1本ショート（原案）
- **フォーマット（45秒）**: 装備品の写真と契約をテンポよく3〜4連発
  「12式地対艦誘導弾 ○○億」「護衛艦の主機 ○○億」→「防衛調達シェア○.○%」
  →「その企業は…○○社でした」→ 株価チャートや本業（民生品）とのギャップで締め
- **量産性**: ベンダー上位300社×年次更新。vendor別契約額・シェアはSQL一発、
  装備品写真は equipment_master の ref_url_hakusho / ref_url_wikipedia から引用元つきで取得
- **使うDB資産**: vendor_name集計（要A-5正規化）、contract_equipment、equipment_master
- **伸びる理由**: 「身近な企業（電池・ベアリング・塗料）が実は防衛」の意外性は
  クイズ型サムネと相性が良い。企業名当てコメント欄が回る
- **注意**: 写真は出典明記（防衛省サイトは政府標準利用規約、WikipediaはCC BY-SA）。
  「シェア」は本DB集計値である旨を画面内に常時表示

## 12. 「今月の防衛調達ランキングTOP10」カウントダウン
- **フォーマット（60秒）**: 月次収集のたびに金額TOP10を10位→1位でカウントダウン。
  BGMとテロップだけで成立、ナレーションはTTSで可
- **量産性**: 月1本×軍種別スピンオフ（陸・海・空・装備庁版）で月5本。
  kit/の増分収集ルーチンが回っていれば**ネタ切れが構造的に存在しない**
- **フック例**: 「今月、防衛省が一番高い買い物をしたのは？」「1位はまさかの燃料○○億」

## 13. 「自衛隊の買い物、いくらでしょう？」クイズ型ショート
- **フォーマット（30秒）**: 調達品名と写真を見せて「いくらで買ったでしょう？」
  →3択→正解発表。ネタはDBの両極端から拾う：1円契約、タクシー借上、楽器、
  医療機器、灯油、そしてF-35
- **量産性**: contract_name のキーワード抽出で「意外な品目リスト」を自動生成可能。
  視聴者参加型なのでコメント率が高く、アルゴリズムに乗りやすい
- **使うDB資産**: contracts全量（金額異常値リストすらネタになる — 監査C-1の副産物）

## 14. 「本日の注目契約」X(Twitter)自動投稿bot
- **フォーマット**: 毎日1件、インフォグラフィック画像（品名・金額・発注機関・
  落札方式・シェア文脈）を自動生成して投稿。完全無人運用
- **量産性**: Python+画像テンプレ（Pillow/HTML→PNG）で**運用コストほぼゼロ**。
  ショート動画への導線・データ販売（#3）の営業窓口を兼ねる
- **選定ロジック**: 金額上位／随契99%超／1社応札／新規ベンダー初登場 などを
  ルールでローテーション — 監査用クエリがそのままネタ選定器になる

## 15. 「うちの県の防衛産業」47都道府県シリーズ
- **フォーマット（60秒）**: 県ごとに「県内企業の受注総額」「最大の1社」「意外な1社」
  「近くの基地の発注額」。ご当地ネタは地元視聴者の保存・シェアが強い
- **量産性**: vendor_address の都道府県抽出で47本が**最初から本数確定**。
  地方紙・地元TVへの企画売り（#8の入口）にもなる
- **使うDB資産**: vendor_address、agency_id（基地粒度）、地方防衛局別集計

## 16. 「買った後が本番」装備品ライフサイクル費シリーズ
- **フォーマット（60秒）**: 「F-35、買うのに○○億。でも毎年の維持費は…」
  取得契約と維持整備契約（P72分類）を時系列で見せ、「氷山の一角」演出で締め
- **独自性**: 取得費は報道されるが**維持費の積み上げを個別契約で示せるのは本DBだけ**。
  ショートで掴み→ロング動画/note記事（#4メディア）で深掘りの2段構え
- **使うDB資産**: contract_equipment×FY時系列、contract_pillar（P72=維持整備）

## ポップ路線の共通設計

- **制作パイプライン**: DB→スクリプトで台本JSON生成→テンプレ動画（Remotion/ffmpeg）
  →TTSナレーション→一括レンダリング。人手は「ネタ選定の最終確認」だけに絞る
- **収益構造**: ショート単体の広告収益は薄い。役割は**認知獲得とDB信頼性の証明**で、
  概要欄から #4ニュースレター・#2アラート・#3データ販売へ流す導線が本体
- **炎上回避**: 特定企業を「軍需企業」とレッテル貼りしない（事実の列挙＋出典のみ）。
  シェア%・金額はすべて公表データの集計値であることを画面内に明示。
  防衛省写真の利用規約クレジット（出典：防衛省ホームページ等）を毎本入れる
- **最初の1本**: #11を三菱重工のような「誰でも知ってる王道」でなく、
  **「えっ、あの会社が？」の中堅企業**から始めるとフォーマットの強さが立証しやすい

## 共通の留意点

- **出典と免責**: 全データは財計第2017号等に基づく公表情報の収集・構造化であり、
  7本柱分類・要求元判定は**独自推定**（confidence付き）であることを必ず明示する。
  推定をファクトとして売ると信頼を失う — confidence列がそのまま商品の誠実さになる。
- **品質前提**: #5（監査）・#7（DD）は、監査レポート（docs/db_quality_audit_20260613.md）
  の A-1/A-3/A-5 修正完了が事実上の前提。
- **更新が価値**: どの案も「FY2026以降の継続収集」が生命線。kit/ の増分収集手順を
  月次ルーチン化してから営業を始めるのが安全。
- **段階戦略**: 初期コストが低く独自性が最大なのは #4（メディア）と #3（データ販売）。
  ここで認知と信用を作り、#1/#2のサブスクへ誘導、最終的に#9のSaaSへ — の順を推奨。
