## 収録内容

各年版は約 100〜150 ページ（PDF 5〜8 MB）で以下を収録：
- 防衛装備庁の組織・沿革
- 調達業務の運営（契約制度、品質管理、価格交渉等）
- 当該年度の調達統計（要求機関別・品目別・契約方式別）
