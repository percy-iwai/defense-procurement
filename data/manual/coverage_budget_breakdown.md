# FY2024 物件費（契約ベース）構造とカバレッジ分析

## 1. 予算構造の関係

```
歳出予算 77,249億円                物件費（契約ベース）93,625億円
（R6に支払う額）                    （R6に締結する契約額）
│                                  │
├ 人件・糧食費    22,290億          ├ 一般物件費（活動経費） 17,032億
├ 歳出化経費      37,928億          │  └ 単年契約・R6締結・R6支払
│  └ 過去契約のR6支払               └ 新規後年度負担          76,594億
└ 一般物件費      17,032億 ◀共通▶        └ R6締結・R7以降支払（多年度）
  （SACO等除く）
```

- **一般物件費（活動経費）17,032億円** は歳出予算・契約ベース双方に登場する唯一の共通項
- **歳出化経費 37,928億** は過去年度に締結した契約のR6支払分であり、93,625億には含まれない
- **公表DB（財計第2017号）は契約締結日ベース** → 93,625億円との直接比較が正しい

**出典**: 防衛省 令和6年度予算の概要（2024-03-28）P.54, P.58

## 2. 差し引き一覧と導出根拠

| 項目 | 金額 | 導出方法 | ソース |
|------|-----:|---------|--------|

| △ 非契約系 | **▲ 約8,500億円** | 行政事業レビューDB 330事業×契約DB完全突合、15事業を非契約に分類 | `jigyou_review.db` + `_analyze_full_coverage.py` + 費目別vendor_name検証 |
| △ 不用額（R6年度決算） | **▲ 約1,200億円** | R6年度決算 官房長官発表（主因:競争入札落差・人件費未充足） | 朝日新聞/日刊ゲンダイ 2025-11-18〜20 |

## 3. 非契約系 内訳（約8,500億円）

| 費目 | 推定非契約額 | 理由 |
|------|------------:|------|
| 営舎費等（光熱水料） | ~1,624億 | 月次少額・公表閾値以下（電力会社/水道局への支払） |
| 基地対策経費等 | ~3,300億 | 補助金・交付金・賃金・借料（RS 15事業から分類） |
| 借料（地主小額連続） | ~1,345億 | 個人地主との小額連続契約 |
| 教育訓練費 | ~390億 | 研修参加費・謝金・小額委託 |
| 医療費等 | ~320億 | 社会保険診療報酬支払基金経由 |
| 補助金確定3件 | ~513億 | 装備移転400億 + サイバー71億 + GIGO42億 |
| その他（一般物件費以外の非契約分） | ~1,000億 | 新規後年度負担内の非契約分（推定） |
| **合計** | **≈ 8,500億円** | |

**検証方法の注意点**: `LIKE '%電気%'` などナイーブなキーワード検索は「新設電気工事」「ガスタービンエンジン」に誤マッチするため、必ずvendor_name（電力会社名・水道局名）で再確認すること。

## 5. 不用額について

- **FY2024不用額**: 約1,172億円（防衛費全体 96,521億中）
- **主因①**: 競争入札により契約額が予定を下回った（落差分）→ 契約は締結済みでDBに計上済み
- **主因②**: 自衛隊員採用数が想定を下回り人件費不用 → 母数外
- **分析上の扱い**: 「実際に締結されなかった予算」として分母から控除（保守的処理）
